QIK Synthetic
=============

This package is part of **QIK (Quant Infrastructure Kit)** and provides
synthetic market series utilities under the `qik.*` namespace.

Install/use with:

- Package import: `from qik.synthetic import DriftConfig, build_market_path`
- CLI: `qik-synthetic`

Planned sibling packages for this namespace:

- `qik-core`
- `qik-validation`
- `qik-metrics`
